# Практика без паники

Интерактивная памятка по учебной и производственной практике. Проект помогает студенту выбрать тип практики, понять комплект документов, отметить готовые файлы и быстро найти ответ на частый вопрос.

## Возможности

- выбор учебной или производственной практики;
- выбор места практики: через университет или самостоятельно;
- чек-лист документов с прогрессом выполнения;
- сохранение отмеченных пунктов в браузере;
- маршрут подготовки по этапам практики;
- универсальная структура отчёта по этапам задания и выбранной предметной области;
- экспорт отчёта о выполнении проекта и презентации в PDF;
- подсказка по вставке подписи на белом фоне;
- финальная проверка перед отправкой в LMS;
- поиск по разделу «Частые вопросы»;
- адаптивная верстка для компьютера и телефона.

## Запуск локально

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

После запуска открой адрес, который покажет терминал.

## Проверка проекта

```bash
npm run build
npm run lint
```

## Структура

- `app/page.tsx` — основной экран и логика памятки;
- `app/globals.css` — тема, цвета и общие стили;
- `app/layout.tsx` — метаданные страницы и корневой layout;
- `components/ui/` — переиспользуемые компоненты интерфейса;
- `public/` — статические изображения и favicon.

## Загрузка в GitHub

Создай пустой репозиторий на GitHub, затем выполни команды из папки проекта:

```bash
git init
git add .
git commit -m "Добавить памятку по практике"
git branch -M main
git remote add origin https://github.com/ТВОЙ_ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ.git
git push -u origin main
```

Не загружай папки `node_modules`, `.next`, `dist` и `.wrangler` — они уже исключены в `.gitignore`.

## Важно

Памятка дополняет официальное задание, но не заменяет требования LMS и руководителя практики. Если в LMS появилось отдельное прямое указание, следуй ему.
