# Практика · высшее образование

Обезличенная интерактивная памятка по практике в высшем образовании. Проект помогает выбрать уровень образования, определить вид и тип практики, понять состав комплекта документов, подготовить договор и быстро найти ответ на частый вопрос.

## Возможности

- выбор уровня: бакалавриат или магистратура;
- для бакалавриата — учебная и производственная практика;
- для магистратуры — вид практики (учебная или производственная) и тип практики (обычная или НИР);
- выбор места для производственной практики: университет или профильная организация;
- чек-лист документов с отдельным прогрессом для каждого вида и места практики;
- сохранение отмеченных пунктов в браузере;
- форматы документов: PDF, DOCX (Word), справка и скан договора;
- пошаговая подсказка по бумажному и электронному договору;
- маршрут подготовки по этапам практики;
- структура отчёта для обычных практик и НИР;
- финальная проверка перед отправкой в LMS;
- поиск по разделу «Частые вопросы»;
- адаптивная верстка для компьютера и телефона.

## Запуск локально

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

После запуска открой адрес, который покажет терминал.

## Проверка проекта

```bash
npm run build
npm run lint
```

## Структура

- `app/PracticeFaqClient.tsx` — основной экран, виды практик и логика чек-листа;
- `app/globals.css` — тема, цвета и общие стили;
- `app/layout.tsx` — метаданные страницы и корневой layout;
- `components/ui/` — переиспользуемые компоненты интерфейса;
- `public/` — статические изображения и favicon.

## Публикация в GitHub Pages

При отправке изменений в ветку `main` GitHub Actions автоматически собирает статическую версию и публикует её через GitHub Pages. Папки `node_modules`, `.next`, `dist` и `.wrangler` исключены из репозитория.

## Важно

Памятка дополняет официальное задание, но не заменяет требования LMS и руководителя практики. Если в LMS появилось отдельное прямое указание, следуй ему.
